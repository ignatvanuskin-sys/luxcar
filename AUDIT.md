## 2. Что нашлось и что исправлено

### Критично

**1. Заявки не доходили до `/admin` на проде.**
На Vercel файловая система деплоя доступна только для чтения, поэтому запись в
`.data/bookings.json` молча падала: `POST /api/bookings` отдавал ошибку, клиент
переключался на `localStorage`, а `GET /api/bookings` возвращал пустой массив.
Итог: клиент оформлял запись, открывал панель — и видел нули.

Исправлено:
* серверная часть пишет в `os.tmpdir()` на serverless и держит кэш в памяти
  инстанса, поэтому `GET/POST/PATCH` работают всегда;
* браузер теперь **всегда** дублирует заявку в локальное зеркало;
* админка **объединяет** серверный список и зеркало (дедупликация по id,
  серверный статус приоритетнее) и помечает строки, которых нет на сервере,
  бейджем «в браузере»;
* в подвале таблицы прямо написано, что это демо-хранилище и что для боевой
  работы нужна БД (интерфейс `BookingStore` уже готов).

**2. `canonical`, Open Graph и JSON-LD указывали на `http://localhost:3000`.**
Превью ссылки в мессенджерах ломалось, поисковики получали неверный канонический
адрес. Причина — не заданная переменная `NEXT_PUBLIC_SITE_URL`.
Исправлено: адрес вычисляется по цепочке `NEXT_PUBLIC_SITE_URL` →
`VERCEL_PROJECT_PRODUCTION_URL` → `VERCEL_URL` → localhost. Теперь деплой
автоматически подставляет свой домен, доступ к дашборду не нужен.

### Средне

**3. Номер заявки обрезался на 390 px** в экране успеха — добавлен перенос строки.

### Мелочи

**4. Рейтинг отображался как «4,8»** при том, что в карточке 2ГИС — «4.8».
Все счётчики приведены к формату источника (точка), тысячи — по-русски.

**5. Лоадер отправки жил ~20 мс** (локальный API отвечает мгновенно) и читался как
мигание. Теперь состояние «Отправляем…» держится минимум 400 мс.

## 4. Добавленные анимации

Принцип: только `transform` и `opacity` (плюс одна маскированная градиентная
рамка), ничего не крутится в фоне, когда элемент вне экрана.

| Источник | Что взято | Как реализовано |
|---|---|---|
| `beam.jakubantalik.com` → libraries.dev/beam | светящаяся рамка | `.beam`: конический градиент в 1px-рамке через `mask-composite`, вращение через `@property --beam-angle`. На карточке рейтинга в hero, блоке рейтинга и блоке карты. Вне экрана анимация ставится на паузу |
| `orbs.jakubantalik.com` | живые сферы | `.orb-a/.orb-b`: два размытых пятна, дрейф 22–27 с, в hero и финальном CTA |
| `transitions.dev` — number pop-in / spinning counter | цифры «набегают» | `CountUp` + `MotionObserver`: счёт с нуля по easeOutExpo, всплытие с блюром. Рейтинг 4.8, 85 оценок, 42 отзыва, 5 фото, счётчики админки |
| `transitions.dev` — texts reveal (two lines rise) | появление hero | `.rise` со stagger-задержками: бейдж → две строки H1 → абзац → кнопки → строка фактов → карточка рейтинга |
| `transitions.dev` — modal open/close | вход диалога | `animate-pop-in` (scale + fade) |
| `transitions.dev` — error state shake | ошибка валидации | `.shake` на сообщениях об ошибке, перезапуск через ключ |
| `transitions.dev` — success check | экран успеха | отрисовка галочки по контуру (уже была) + поп-анимация |
| `transitions.dev` — toast open/close | подтверждение статуса | всплывающий тост в админке, сам скрывается через 3 с |
| `transitions.dev` — shimmer text / sweep | блик на главной кнопке | `.sheen` на основном CTA (hero, шапка, мобильная панель) — не более одного на экран |
| `dotmatrix.zzzzshawn.cloud` | точечный лоадер | `.dot-loader` (сетка 3×3): отправка заявки и загрузка списка в админке |
| `arloui.com` (input) | анатомия поля | подписи, вставной префикс «+7», helper/error-текст, состояния фокуса и ошибки |
| `transitions.dev` — step transitions | переходы шагов | `.step-forward` / `.step-back`: шаг выезжает в сторону движения |

**Сознательно не использовано.** WebGL-эффекты (`canvasui.dev`, `originkit.dev`,
`metal.jakubantalik.com`) не подключались: это тяжёлые шейдеры, которые на
средних Android-телефонах роняют FPS и батарею, а ТЗ прямо запрещает превращать
сайт в презентацию эффектов. Атмосфера сделана CSS-орбами и рамками.

**Доступность.** Всё уважает `prefers-reduced-motion: reduce`: анимации
отключаются, счётчики сразу показывают конечные значения, скрытые состояния
снимаются. Проверено.

## 6. Ревизия 2 — прогон живого прода в браузере

После добавления анимаций сайт был прогнан заново уже по живому деплою
(390×844, 320×568, 1440×900, 1280×720). Нашлись ещё четыре дефекта — все
исправлены и перепроверены на проде.

| Дефект | Причина | Исправление | Проверка |
|---|---|---|---|
| Диалог записи на 320×568: верх и кнопка закрытия уходили за экран и были недостижимы | `items-end` стоял прямо на скролл-контейнере: flex-элемент выше вьюпорта вылезает за start-край, который не входит в область прокрутки | выравнивание перенесено на внутреннюю обёртку с `min-h-full` | прод: dialog top **0**, кнопка закрытия top **17**, оверлей скроллится (885/568), закрытие работает; то же на 1280×720 |
| Горизонтальное переполнение **9 px** на 320×568 в блоке контактов | кнопка «Записаться на обслуживание» с `nowrap` поднимала min-content сетки до 298 px при доступных 310 → трек не сжимался | у кнопок появился режим `wrap`, карточкам добавлен `min-w-0` | прод: 320 → scrollWidth **310 = clientWidth**, `scrollTo(60,0)` → `scrollX 0`; 375 и 390 → 0; карточки внутри вьюпорта |
| В админке бейдж «в браузере» исчезал после смены статуса | ветка локального обновления возвращала строку без `origin` | возвращает `{ ...updated, origin: "local" }` | прод: бейдж виден сразу после смены и сохраняется после перезагрузки |
| Повторные `PATCH → 404` для уже помеченной строки | проверка запомненного id использовала `??`, который не срабатывает на явном `false` | заменено на `||` + id запоминается в `localStorage` | прод: 2-я и 3-я смены статуса → **0 запросов**, бейдж на месте |

Дополнительно: пробел между строками H1 (скринридер и копирование читали
«так,чтобы») и регрессионный тест `scripts/booking-store.test.mjs` (12 проверок,
включая оба случая с пометкой строк).

### Что подтверждено на живом проде (финальная приёмка)

* Переполнения по горизонтали нет на 320 / 375 / 390 px, в том числе с открытым
  диалогом; `scrollTo(60,0)` не сдвигает страницу.
* Диалог записи: `top 0`, кнопка закрытия доступна и кликабельна, оверлей
  прокручивается, закрытие работает.
* Полный сценарий записи на 390 px: маска телефона корректна, экран успеха
  появляется, номер заявки не обрезается.
* Админка: счётчики видимы и показывают числа, строки помечаются корректно,
  смена статуса на помеченной строке не делает лишних запросов.
* Консоль: **0 ошибок и предупреждений**; в сети — только один исторический
  `PATCH → 404`, оставшийся от прошлого прогона (до фикса).
* Скорость: DCL **101,6 мс**, load **177,3 мс** (390 px).
* Органический CLS **0,0047** (инструмент проверен искусственным сдвигом
  0,237 — измерение достоверно).
